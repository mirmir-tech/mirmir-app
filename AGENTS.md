# Mirmir for Mac — agent notes

This repository owns the native macOS application: a SwiftUI client of
mirmir's `Runtime` gRPC service with a menu bar panel, a main window and
instance management. It contains no inference engine. Read
`docs/architecture.md` before changing layers or the transport.

## Boundaries

- `Proto/mirmir.proto` is a copy of `mirmir/proto/mirmir.proto`. Refresh it
  with `scripts/generate-proto.sh --sync`; never edit it here first. Protocol
  changes start in the `mirmir` repository.
- `Sources/MirmirRPC/Generated` is generated by `scripts/generate-proto.sh`.
  Never edit it by hand.
- `Sources/MirmirKit`: typed domain, protocol decoding, the gRPC connection,
  the local server supervisor, stores and the observable app model. No SwiftUI
  views.
- `Sources/MirmirApp`: SwiftUI scenes and views only. Views never see protobuf
  types.
- Do not link `libmir` or any Rust crate into the app. Missing data is a
  protocol gap to close in `mirmir`, not a reason to embed the runtime.

## Engineering rules

- Decode protocol strings (`state`, `kind`, `stage`, `phase`) into Swift enums
  once, in `MirmirKit/Protocol`. Never compare display strings in views or the
  app model.
- Typed models must make invalid states unrepresentable: prefer enums with
  associated values over parallel optionals and booleans.
- A value the server does not report is shown as unavailable (`—`), never as
  zero or an invented number.
- Colors come only from `Palette` (the website tokens, light and dark). Do not
  leave system grey backgrounds next to palette surfaces: use
  `paletteBackground` on lists, tables and forms.
- Keep Swift files focused; split before a file passes about 250 lines.
- `swift build` and `swift test` must stay warning-free.
- Do not commit or push unless the user asks.

## Running against a test server

The app resolves the personal socket like mirmir (`XDG_RUNTIME_DIR`,
`MIRMIR_STATE_HOME`, `XDG_STATE_HOME`, `~/.local/state/mirmir`) and starts
`MIRMIR_BINARY` or `mirmir` from `PATH` when no server answers. To avoid
touching the user's models, point `MIRMIR_CONFIG_HOME` and `MIRMIR_STATE_HOME`
at a scratch directory and `XDG_RUNTIME_DIR` at a short path: Unix socket
paths are limited to 104 bytes.
